# 하루 캘린더

시간 없이 날짜별로 할 일을 관리하는 개인용 PWA 캘린더입니다. (모바일 기준, 라이트 모드, 메인 색 `#FFCA2A`)

## 기능

- 월간 / 주간 / 일간 보기 (좌우 스와이프로 이동)
- 할 일 추가 · 수정 · 완료 체크 · 삭제
- 시간 설정 on/off (끄면 날짜만 있는 할 일)
- 할 일마다 색상 지정 (9가지)
- 반복 일정 한 번에 등록: 요일과 기간(3개월/6개월/1년)을 고르면 한꺼번에 등록
  - 예: 월·화 미술학원, 수·목·금 편의점 1년치
  - 일정 하나를 눌러 "이후 반복 일정 모두 삭제"도 가능
- 텍스트로 가져오기: 복사한 스케줄을 붙여넣으면 날짜별로 정리 (API 없음)
  - `11월`, `27년`, `14일 (토) 제목`, `11/14 제목` 형식을 인식
  - 요일 불일치, 날짜 중복, 날짜 미정 항목은 "확인 필요"로 표시
- 백업 파일 내보내기 / 불러오기 (JSON)
- 오프라인에서도 동작 (서비스 워커)

## 실행 (Mac)

```bash
node dev-server.mjs
```

브라우저에서 http://localhost:5180 을 엽니다.

## 아이폰에 설치

서비스 워커와 홈 화면 앱은 **https** 주소가 필요합니다. 무료 호스팅에 올린 뒤 아이폰 Safari에서 열고 **공유 → 홈 화면에 추가**를 누르세요.

- GitHub Pages 또는 Vercel에 이 폴더를 그대로 올리면 됩니다 (빌드 단계 없음).

## 파일 구조

| 파일 | 역할 |
|---|---|
| `js/store.js` | 데이터 저장소 (모든 읽기/쓰기). 나중에 위젯 연동 시 여기만 수정 |
| `js/parser.js` | 텍스트 → 날짜별 할 일 규칙 파서 |
| `js/recurrence.js` | 요일 반복 일정 펼치기 |
| `js/app.js` | 화면과 상호작용 |
| `js/dates.js`, `js/colors.js` | 날짜·색상 유틸 |
| `sw.js`, `manifest.webmanifest`, `icons/` | PWA 설정 |
